# Hospital Information System — PostgreSQL Database

Проектирование реляционной базы данных и серверной логики на **PostgreSQL / PL/pgSQL** для информационной системы медицинского учреждения.

## Структура репозитория
* `Создание таблиц для БД` — DDL-скрипт создания 8 нормализованных таблиц с ограничениями целостности (`PRIMARY KEY`, `FOREIGN KEY`, `IDENTITY`).
* `Заполнение таблиц данными.sql` — DML-скрипт наполнения справочников и связующих таблиц тестовыми данными.
* `Аналитические запросы на выборку.sql` — аналитические запросы (`INNER JOIN`, фильтрация, агрегации, `GROUP BY`, `HAVING`).
* `Представления, JSONB, функции и триггеры.sql` — представления (`VIEW`, `MATERIALIZED VIEW`), работа с `JSONB`, хранимые функции и триггеры (`PL/pgSQL`).
